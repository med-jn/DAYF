# Tik Guest

ضيف صوتي بالذكاء الاصطناعي لبثوث تيك توك المباشرة (أندرويد). الحزمة: `com.tikguest`.

- تسجيل الدخول بجوجل (Supabase Auth)، وشخصيات خاصة بكل مستخدم بأمان RLS.
- مفتاح Gemini خاص بالمستخدم: مشفّر على جهازه وفي حسابه.
- لا نخزّن ما يقوله الآخرون في البث. الذاكرة في RAM أثناء الجلسة فقط.
- لقطات الشاشة عند الحاجة فقط.

الإعداد والبناء والنشر: `SETUP.md`. مخطط قاعدة البيانات: `supabase/schema_v2.sql`. الخصوصية: `docs/index.html`.
